# 前端运行说明

## 页面访问流程

- 访问 `http://localhost:80/` 后，直接显示完整的独立可视化大屏。
- 点击大屏右上角“后台管理”，未登录时先进入原登录页面。
- 输入原系统账号和密码后，进入原有后台管理首页。
- 点击后台顶部“可视化大屏”，可返回独立可视化界面。

## 本地开发运行

项目主目录：`frontend/frontend`

在该目录打开 PowerShell 或 VSCode 终端，依次执行：

```powershell
npm install
npm run dev
```

终端会显示访问地址，通常为 `http://localhost:80/`；具体端口以 `vite.config.js` 为准。

## 正式打包

```powershell
npm run build:prod
```

打包结果位于：`frontend/frontend/dist`

## 主要路由

- `/`：自动进入独立可视化大屏
- `/screen`：独立可视化大屏（无需登录）
- `/login`：原登录页
- `/index`：自动进入后台基地地块地图
- `/admin`：后台入口，自动进入基地地块地图
